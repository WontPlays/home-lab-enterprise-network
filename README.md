# Enterprise Home Lab (Windows Server + Linux + Networking)

## Overview

This project simulates a small enterprise IT
infrastructure buit in a virtualized enivronment using Hyper-V.

The goal is to practice real-world system administration, networking
and infrastructure design skills by building a mini corporate network from scratch.

The lab evolves over time and includes:
- Windows Server domain enivronment
- Active Directory setup
- DNS integration
- Linux Server with web services
- Internal network segmentation
- Basic troubleshooting and diagnostics

## Objectives

- Learn and practice enterprise-level system administration concepts
- Build and understand internal corporate network architecture
- Configure Windows Server with Active Directory services
- Practice network troubleshooting and service diagnostics
- Develop infrastructure documentation habits
